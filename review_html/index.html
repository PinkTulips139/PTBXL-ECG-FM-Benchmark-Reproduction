Known limitations

  • Two of 78 physical canonical sample bundles are unavailable and are shown as provenance-only entries.
  • One run has a historical strict-mapping blocker; five runs have Bootstrap provenance blockers.
  • Checkpoint binaries are not packaged.
  • Reviewer shards are serialized inspection data, not independent scientific results.
  • No fixed classification threshold defines “correct” or “incorrect” here.
  • Larger paper-versus-ours differences are not assigned unproven causal explanations.
